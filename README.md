# Portfolio Angular

Karim CHARLEUX's portfolio — Angular 22, standalone, zoneless, SSR, Vitest.

## Development

Requires Node 24 (see `.nvmrc`).

```bash
nvm use
npm install
npm start
```

Navigate to `http://localhost:4200/`.

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Deploy

```bash
npm run deploy
```
